def parse(line: str) -> dict[str, int]:
    """Split 'key=value' pairs; ignore #comments."""
    out = {}
    for part in line.split(";"):
        k, _, v = part.partition("=")
        if k and not k.startswith("#"):
            out[k.strip()] = int(v or 0)  # 0x1F, 1_000
    return out

Details

  • Every character is 0.6 em wide, spaces included.
  • About 3,000 characters: Latin, Greek, Cyrillic, arrows, maths, box drawing.
  • Slashed zero, flag one, tailed l and serifed I by default.
  • No kerning and no ligatures, so columns always line up.
  • Built by script from Inter 18pt, version 4.001. Regular and Italic only.
